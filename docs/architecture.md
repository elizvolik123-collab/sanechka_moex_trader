# Карта MOEX Trader

| Путь | Ответственность |
| --- | --- |
| `src/app/`, `src/components/` | Интерфейс на русском, Next.js App Router, API, формы. |
| `src/core/` | FIFO, импорт, статистика и риск: функции без БД, юнит-тесты рядом. |
| `src/server/` | PostgreSQL, авторизация Better Auth, шифрование токенов, адаптер Т‑Инвестиций, MOEX ISS, журнал, новости. |
| `src/worker/` | pg-boss на той же PostgreSQL: обновление справочника и новостей, задания синхронизации брокера. |
| `prisma/` | Схема и миграции. Клиент генерируется в `src/generated/prisma` при установке. |
| `scripts/`, `deploy/` | Инструменты локального запуска, тестовые данные, Caddy, копии базы. |

Данные дневника фильтруются по владельцу. Сделки — производные от исполнений: позиция от нуля до нуля, частичные закрытия и перевороты учитываются FIFO. Суммы в БД — Decimal. Комиссии относятся к исполнениям, НКД — к P&L облигаций; пополнения, дивиденды и налоги остаются денежными операциями. Повторный импорт дедуплицируется по счёту и внешнему ID (либо хэшу строки). Начальный капитал для файлового счёта задаётся вручную.

Калькулятор округляет цены по шагу и учитывает комиссию, лотность и ГО. Источник котировки — MOEX ISS, цена может приходить с задержкой. План пересчитывается на сервере. Токены брокера шифруются AES-256-GCM с версией ключа, полное значение не возвращается в интерфейс.

Новости берутся из публичного веб-превью канала, HTML очищается перед сохранением. Файлы новостей, логотипы и локальная почта попадают в `.data`. База и воркер нужны для синхронизации; сервер web можно проверять отдельно от воркера.

Из брокеров поддерживаются Т‑Инвестиции. Операции в иностранной валюте не становятся сделками, переводы и экспирации показываются как пропущенные. Для XLSX Т‑Банка нет проверенного готового пресета: используйте автоопределение или ручное сопоставление. Лимиты запросов web хранятся в памяти процесса.
